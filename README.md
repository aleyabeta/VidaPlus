# VidaPlus
Sitio web académico de servicios no tecnológicos desarrollado en HTML, CSS y JavaScript.

## Páginas
- `index.html`: inicio y descripción de dos servicios.
- `servicio1.html`: entrenamiento personal (estudiante 1).
- `servicio2.html`: asesoramiento nutricional (estudiante 2).

## Ejecución
Abrir `index.html` en un navegador o usar Live Server en VS Code.

## Colaboración
Cada estudiante desarrolla su servicio en una rama independiente (`feat/servicio1` y `feat/servicio2`) y abre un pull request a `main`. Los formularios son demostrativos y no envían información.
